# Фреймворк — Архитектурный подход

Spiral — PHP-фреймворк, цель которого — упростить разработку сложных веб-приложений. Один из его ключевых принципов —
прагматичное проектирование с соблюдением принципов Keep It Simple, Stupid (KISS) и SOLID.

## Принципы

Принцип KISS требует проектировать программное обеспечение настолько просто, насколько это возможно, сводя количество
движущихся частей к минимуму. Благодаря этому код проще понимать, тестировать и сопровождать. SOLID, в свою очередь, —
это набор из пяти принципов объектно-ориентированного проектирования, направленных на повышение сопровождаемости и
масштабируемости программного обеспечения.

### По возможности избегайте перекрёстных зависимостей

Одним из основных механизмов Spiral является внедрение зависимостей. Оно помогает избегать перекрёстных зависимостей
между компонентами и способствует слабой связанности. Благодаря этому один компонент можно легко заменить другим, не
затрагивая остальную систему.

### Отдавайте предпочтение композиции, а не наследованию

Ещё одна важная особенность Spiral — предпочтение композиции наследованию. Такой подход предполагает создание новых
объектов путём объединения других объектов вместо построения сложных иерархий классов. Это обеспечивает большую
гибкость и упрощает изменение поведения объекта во время выполнения программы.

### Предпочитайте небольшие, но содержательные интерфейсы

Spiral также отдаёт предпочтение небольшим, но содержательным интерфейсам. Интерфейсы должны оставаться максимально
простыми и содержать минимально необходимое количество методов. Это упрощает их реализацию и повышает вероятность того,
что реализующий интерфейс класс будет обладать корректным поведением.

### Избегайте магии

Spiral рекомендует избегать «магии» в коде. Код должен быть максимально явным и не должен опираться на скрытые побочные
эффекты или другие неочевидные конструкции. Цель — сделать его как можно более понятным.

## Гибридная среда выполнения

Фреймворк использует сервер приложений [RoadRunner](https://roadrunner.dev) для запуска части своих сервисов. Кодовая
база на PHP в основном сосредоточена на быстрой и эффективной реализации бизнес-логики. Сервер приложений, написанный на
Go, предназначен для эффективного решения инфраструктурных задач.
