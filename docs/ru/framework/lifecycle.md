# Фреймворк — Жизненный цикл приложения

Spiral можно использовать в традиционной конфигурации Nginx/PHP-FPM, где Nginx выступает веб-сервером, а PHP-FPM
обрабатывает входящие запросы и инициализирует приложение. Однако такой подход может требовать значительных ресурсов,
поскольку для каждого входящего запроса снова расходуются процессорное время и память.

![Инициализация HTTP через Nginx](https://user-images.githubusercontent.com/773481/211190445-06c17d86-58d6-43d8-995f-36cf448714ae.jpg)

Для повышения производительности приложения Spiral можно использовать альтернативное решение — сервер приложений
[RoadRunner](https://roadrunner.dev/).

RoadRunner — высокопроизводительный сервер приложений, предназначенный для обработки различных типов запросов, включая
HTTP, gRPC, TCP, задания очередей и Temporal. При запуске он создаёт воркеры один раз, после чего направляет запросы в
[диспетчер](../framework/dispatcher.md) в зависимости от их типа. Каждый воркер изолирован и работает независимо,
следуя подходу «ничем не делиться», при котором ресурсы между воркерами не разделяются.

> **Примечание**
> Такой способ запуска приложения похож на подход, используемый в **Java**, **C#** и других языках.

Это позволяет разработчикам писать код привычным образом и горизонтально масштабировать воркеры, улучшая использование
ресурсов и увеличивая пропускную способность при обработке входящих запросов.

![Инициализация HTTP через RoadRunner](https://user-images.githubusercontent.com/773481/211197998-96b09ff1-4ede-4db0-9b1d-902e996920be.jpg)

Использование RoadRunner позволяет значительно повысить скорость и эффективность приложения, поскольку избавляет от
необходимости повторно выполнять полный процесс начальной загрузки. Это снижает потребление процессорных ресурсов и
памяти, а также сокращает время ответа.

Кроме того, RoadRunner делает начальную загрузку приложения более гибкой. Например, конфигурацию или маршруты можно
загружать из разных источников — атрибутов или файлов — без необходимости специально кешировать их. Благодаря этому
приложение проще изменять и обновлять.
