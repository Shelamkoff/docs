# Контейнер — Автоматическое связывание

Spiral старается скрыть реализацию и конфигурацию контейнера от доменного слоя, предоставляя развитые возможности
автоматического связывания. Правила автосвязывания достаточно просты, но их необходимо понимать, чтобы избежать
неожиданного поведения фреймворка.

Класс `Spiral\Core\Container\Autowire` позволяет передать параметры контейнеру и предоставить классам определённые
значения конфигурации без жёсткого задания в коде. Это отделяет настройки от реализации и позволяет изменять поведение
приложения без изменения самих классов.

```php app/config/session.php
use Spiral\Core\Container\Autowire;
use Spiral\Session\Handler\FileHandler;

return [
    // ...
    'handler' => new Autowire(
        FileHandler::class,
        [
            'directory' => directory('runtime') . 'session',
            'lifetime' => (int)env('SESSION_LIFETIME', 86400),
        ]
    ),
];
```

При разрешении объекта `Autowire` контейнер автоматически создаст экземпляр `FileHandler` и передаст параметры
`directory` и `lifetime` его конструктору.

Так классы можно настраивать и снабжать определёнными параметрами без жёстко заданных значений. Подход особенно удобен
для классов с большим количеством параметров или используемых в разных частях кодовой базы.
