# Обзор — Версионирование

Все компоненты Spiral следуют правилам [семантического версионирования](https://semver.org/). Нарушение обратной
совместимости допускается только в выпусках, связанных с безопасностью.

## Текущая версия

Текущая версия фреймворка — `3.*`. Предыдущие выпуски можно найти
[здесь](https://github.com/spiral/framework/releases).

| Версия     | PHP   | Дата выпуска | Завершение разработки новых возможностей |
|------------|-------|--------------|------------------------------------------|
| 0.*        | ≥ 5.0 | ноябрь 2013  | декабрь 2017                             |
| 1.*        | ≥ 7.2 | апрель 2017  | декабрь 2019                             |
| 2.*        | ≥ 7.4 | май 2019     | декабрь 2022                             |
| <b>3.*</b> | ≥ 8.1 | сентябрь 2022| —                                        |
