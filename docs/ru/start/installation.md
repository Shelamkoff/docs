# Начало работы — Установка

Spiral предоставляет удобный установщик приложений, с помощью которого можно легко установить и настроить фреймворк,
а также необходимые пакеты через интерфейс командной строки. Он ускоряет начало работы со Spiral и упрощает подготовку
среды разработки.

Установщик особенно полезен для добавления конфигурационных файлов, переменных окружения и загрузчиков, необходимых
выбранным пакетам и компонентам. С его помощью можно установить, в частности:

- [интеграцию с Cycle](../basics/orm.md);
- [валидаторы](../validation/factory.md);
- [диспетчер событий](../advanced/events.md);
- [интеграцию с RoadRunner](../start/server.md);
- [интеграцию с Temporal](../temporal/configuration.md);
- [планировщик заданий Cron](../advanced/scheduler.md);
- [интеграцию с Sentry](../basics/errors.md);
- шаблонизатор [Stempler](../views/stempler.md) или [Twig](../views/twig.md);
- [сериализатор](../advanced/serializer.md);
- [компонент отправки почты](../advanced/sendit.md);
- [метрики RoadRunner](../advanced/prometheus-metrics.md).

Наличие готовых и правильно настроенных пакетов экономит время и усилия при подготовке среды разработки и запуске
проекта.

## Требования к серверу

Убедитесь, что на сервере установлены подходящая версия PHP и необходимые расширения:

* PHP 8.1 или новее, 64-битная сборка;
* расширение *mb-string* — Spiral ориентирован на UTF-8;
* расширение *socket*;
* расширение *curl*;
* расширение *zip*.

## Установка

Процесс установки максимально прост. Для создания нового проекта выполните следующую команду:

```terminal
composer create-project spiral/app my-app
```

После этого вы увидите примерно следующий вывод:

```output
[32mCreating a "spiral/app" project at "./my-app"[39m
[32mInstalling spiral/app (1.1.1)[39m
  - Installing [32mspiral/app[39m ([33m1.1.1[39m): Extracting archive
[32mCreated project in /var/www/my-app[39m
> Installer\Installer::install

  [30;46mWhich application preset do you want to install?[39;49m
  [[33m1[39m] Web
  [[33m2[39m] Cli
  [[33m3[39m] gRPC
  Make your selection [33m(1)[39m:
```

> **Примечание**
> Если во время установки произошла ошибка, процесс всегда можно повторно запустить командой `composer install`.

После установки приложения в корневом каталоге проекта будет создан файл `README.md` с инструкциями по запуску сервера
приложений и самого приложения.

> **Предупреждение**
> Сервер приложений RoadRunner будет загружен автоматически. Для этого необходимы `php-curl` и `php-zip`.

## Запуск сервера

Чтобы запустить сервер приложений, выполните соответствующую команду.

:::: tabs

::: tab Linux

Для запуска RoadRunner в **Linux** используйте:

```terminal
./rr serve
```

> **Предупреждение**
> Убедитесь, что бинарному файлу `rr` разрешено выполнение.

:::

::: tab Windows

Для запуска RoadRunner в **Windows** используйте:

```terminal
.\rr.exe serve
```

:::

::::

По умолчанию приложение будет доступно по адресу `http://localhost:8080`.
